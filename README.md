# Arch 05 — Hybrid &amp; Encoder-Decoder Architectures

A deep technical dive into architecture patterns beyond vanilla decoder-only transformers: Jamba and Zamba's Mamba-attention interleaved designs, the rationale for mixing recurrence with full attention, T5 and FLAN-T5 as encoder-decoder workhorses for structured tasks, when bidirectional encoding beats causal generation, modern use-cases for encoder-decoder models, byte-level and character-level approaches (ByT5, Charformer), and a practical decision tree for choosing the right architecture for a given task.
